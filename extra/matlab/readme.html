MATLAB Examples / MATLAB 示例

English

Our SDK provides MATLAB example files. Please choose the correct files based on your MATLAB version:

  • For MATLAB versions earlier than 2016a: `demomatlab2015.fig` and `demomatlab2015.m`
  • For MATLAB version 2016a or later: `demomatlab2016.mlapp`

中文

本 SDK 提供 MATLAB 示例文件，请根据 MATLAB 版本选择正确的文件：

  • MATLAB 版本低于 2016a：使用 `demomatlab2015.fig` 和 `demomatlab2015.m`
  • MATLAB 版本 2016a 及以上：使用 `demomatlab2016.mlapp`
